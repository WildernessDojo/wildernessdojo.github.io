01 / SYSTEM VIEW

One field loop. Four layers.

SPARROW connects solar-powered sensing, edge inference, cloud analytics and human expertise into a single feedback loop for wildlife monitoring.

🎙️ CAPTURE

Bioacoustic data collection with autonomous recorders (ARUs) in remote field locations.

🧠 COMPUTE

ONNX models running on edge devices, including MegaDetector, bioacoustic classifiers and embedding models.

☁️ CLOUD

Scalable processing, model versioning, and experiment tracking for validation and improvement.

02 / 75-MINUTE DOJO

From tensor to trail.

Orient

Intro to SPARROW, ONNX and edge ML for conservation. ~10 min.

Inspect

Iterate

03 / MODEL MAP

Know what each net does.

Detection answers "where and what broad category;" embedding answers "is this the same individual?" Classifiers answer "what species, call type, behavior?"

MegaDetector

ONNX animal/person/vehicle detection. Used to filter noise and focus labeling effort on frames with animals.

Bioacoustic

Audio classification models for species ID and call type. Trained on focal recordings and field data.

Embeddings

Dimensionality reduction and similarity learning. Clusters similar calls, helps with manual review workflows.
